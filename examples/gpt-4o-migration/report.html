Baseline openai:gpt-4o-mini-2024-07-18

```python
import re

def slugify(title: str) -> str:
    # Lowercase the title
    title = title.lower()
    # Replace runs of non-alphanumeric characters with a single hyphen
    title = re.sub(r'[^a-z0-9]+', '-', title)
    # Strip leading/trailing hyphens
    title = title.strip('-')
    return title
```

Candidate openai:gpt-6-luna

```python
def slugify(title: str) -> str:
    parts = []
    in_separator = False

    for char in title.lower():
        if char.isalnum():
            parts.append(char)
            in_separator = False
        elif parts and not in_separator:
            parts.append("-")
            in_separator = True

    return "".join(parts).rstrip("-")
```
